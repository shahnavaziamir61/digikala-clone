# Tourbillon wall clock — 300 mm dial, visible one-minute flying tourbillon

A parametric OpenSCAD design for a mechanical wall clock whose **tourbillon is
visible from the dial side**, driven by a going barrel, with a real Swiss lever
escapement inside a rotating carriage.

> ## Read this first
>
> This repository contains a **verified geometric and kinematic design**. It is
> **not** a demonstration that a clock works, and nothing in it should be
> described as a working mechanical clock.
>
> A CAD model cannot prove timekeeping. Friction, lubrication, amplitude,
> isochronism, thermal drift, positional error and the hairspring's real rate all
> have to be measured on a built movement with a timegrapher. Every part that is
> not proven is labelled, and every limitation is listed in
> **[`docs/LIMITATIONS.md`](docs/LIMITATIONS.md)** — read it before building
> anything.
>
> Every part in the model carries one of three labels, enforced by the exporter:
>
> | label | meaning |
> |---|---|
> | **Functional** | has a defined mechanical function, dimensions and a relation to other parts |
> | **Prototype** | functionally defined but a parameter is set by bench adjustment, not by calculation (the click, the winding sleeve, the canon pinion's friction grip) |
> | **Decorative-reference** | a reference shape only. **The exporter refuses to write an STL for these**, so a decorative part can never be mistaken for a printable functional one |

## Architecture (fixed before any file was generated)

Going-barrel wall-clock movement, **rim-driven single-axis flying tourbillon**
(Helwig / IWC Mystère style), **fixed concentric fourth wheel**, **Swiss lever
escapement inside the rotating carriage**.

**Power path**

```
mainspring
  -> BARREL DRUM + barrel gear (z14, m1.40)
  -> GREAT WHEEL (z56)                      i = 4.000
  -> great pinion (z8, m0.75) -> CENTRE WHEEL (z48)   i = 6.000   1 rev/hour
  -> centre pinion (z10, m0.60) -> INTERMEDIATE WHEEL (z75)
  -> intermediate pinion (z12, m0.70) -> CARRIAGE RIM GEAR (z96)  carriage 1 rev/min
```
barrel → centre wheel **24.000 : 1**, centre wheel → carriage **60.000 : 1**.

**Escapement path** (inside the carriage, which rotates)

```
FIXED FOURTH WHEEL (z40, m0.45)   STATIONARY, bolted to the main plate,
        ^                         concentric with the carriage axis, reached
        |                         through the Ø30 opening in the carriage floor
ESCAPE PINION (z10)   planet, rigid with the escape wheel, toothed section
        |             hangs BELOW the carriage floor
ESCAPE WHEEL (15 teeth, Swiss club, OD 20.0)
        |
PALLET LEVER (2 ruby stones, entry 12° / exit 10°, draw 12°, lock 1.5°/stone)
        |
ROLLER + impulse pin -> BALANCE (Ø28) + HAIRSPRING at 1.000 Hz
```

The carriage rate follows from the escapement, not from a wish:

```
omega_carriage = f * z_EP / (z_E * z_4) = 1.000 * 10 / (15 * 40) = 1.000 rpm
```

so the tourbillon **is** the seconds display. The epicyclic ratio is 4.000, the
escape wheel turns at 5.000 rpm absolute (4.000 relative to the carriage) and
passes 1.000 tooth/s — exactly the 1.000 Hz beat.

**Motion works** `(64/16) × (48/16) = 12` exactly, on one stud at (28.800, 0).
This needs **two different modules** (0.72 and 0.90); a single module cannot
close both meshes on one stud distance — see L-05 and check C-07b.

**Winding:** key from the front through the dial aperture, 10 mm square on a
sleeve inside the Ø60 barrel arbor, ratchet z24 m1.5 with a click. **There is no
maintaining power** (L-04): the clock stops while you wind.

## Files

### The CAD (OpenSCAD)

`main.scad` is the single entry point; it includes everything else. The
dependency order is strict and one-directional — no file includes a file that
includes it.

```
parameters_auto.scad   MACHINE GENERATED by tools/calc.py.  Do not edit.
        ^
parameters.scad        every user-editable knob, the tolerance presets, the
        ^              Z stack, materials, colours, fasteners
gear_generator.scad    involute + cycloidal tooth geometry, escape wheel,
        ^              ratchet.  The only file that knows how to draw a tooth.
        |
  +-----+--------+-------------+--------------+----------------+
  |              |             |              |                |
mainspring_   wheel_train   motion_works  escapement     bridges_and_plates
barrel            |             |         (carriage-     dial_and_case
  |              |             |          local)  ^     shafts_and_bearings
  |              |             |          tourbillon_cage
  +--------------+-------------+--------------+----------------+
                                  |
                             assembly.scad        the complete clock, true
                                  |               positions; front/back/side/
                                  |               top/iso/section views
                          exploded_view.scad      the same parts pulled apart in
                                  |               assembly order
                          parts_export.scad       one STL per part, with each
                                  |               part's label, process and
                               main.scad          material
```

To work on one subsystem, open its own file — each one is self-contained and
renders on its own.

### The engineering source of truth (Python)

| file | role |
|---|---|
| `tools/gearmath.py` | involute **and** cycloidal tooth geometry. The single source of truth; `gear_generator.scad` mirrors it by hand and the linter proves they agree. |
| `tools/design.py` | every frozen dimension: tooth counts, modules, centre distances, axis positions, barrel and spring, carriage internals, Z stack, manufacturing presets. |
| `tools/calc.py` | the calculator and validator (**46 checks**), and the generator of `parameters_auto.scad`, `design.json`, `BOM.csv` and the docs. |
| `tools/profile_check.py` | measures the **generated tooth profiles** (**77 measurements**): closure, tip thickness, undercut, mesh clearance, contact ratio. |
| `tools/scad_lint.py` | static validation of the `.scad` sources (**11 check families**). |
| `tools/gen_stl.py` | an **independent second implementation** of the part geometry that writes verified binary STL, with no OpenSCAD. |
| `tools/gen_drawings.py` | generates both SVG drawings from the same constants. |

## Using it

```sh
openscad main.scad                                        # front view
openscad -D 'VIEW="iso"'          main.scad                # isometric
openscad -D 'VIEW="tourbillon"'   main.scad                # carriage close-up
openscad -D 'EXPLODED_VIEW=true'  main.scad                # exploded, in order
openscad -D 'SHOW_GEAR_TEETH=false'          main.scad      # fast preview
openscad -D 'SHOW_INTERNAL_MECHANISM=false'  main.scad      # case + dial only
openscad -D 'CROSS_SECTION=true'             main.scad      # Z-stack section
openscad -D 'MANUFACTURING="fdm"'            main.scad      # FDM tolerances
openscad -D 'DRIVE_FROM_TRAIN=true' -D '$t=0.4' main.scad   # geometric animation

# one STL per part
openscad -o stl_output/carriage_floor.stl \
         -D 'PART_TO_EXPORT="carriage_floor"' main.scad
```

The parameters the brief asks for by name are all declared up front in
`parameters.scad`, so they can be driven from the command line:
`CLOCK_DIAMETER`, `TOURBILLON_DIAMETER`, `GEAR_MODULE`, `GEAR_PRESSURE_ANGLE`,
`GEAR_BACKLASH`, `PLATE_THICKNESS`, `SHAFT_DIAMETER`, `AXIAL_CLEARANCE`,
`RADIAL_CLEARANCE`, `BEARING_SEAT_DIAMETER`, `PRINT_TOLERANCE`, `EXPLODED_VIEW`,
`SHOW_GEAR_TEETH`, `SHOW_INTERNAL_MECHANISM`, `PART_TO_EXPORT`.

`MANUFACTURING = "fdm" | "resin" | "metal"` selects a whole tolerance preset at
once (fit clearance, axial play, radial play, backlash, hole growth, minimum
wall and hole, and whether the escapement is permitted at all).

## Verification

Everything below was **actually executed**. Nothing is claimed that was not run.

```sh
python3 tools/calc.py --report      # 46 checks,      0 failed
python3 tools/profile_check.py      # 77 measurements, 0 failed
python3 tools/scad_lint.py          # 15 files,        0 findings
python3 tools/gen_stl.py --self-test # 0 failures
python3 tools/gen_drawings.py       # regenerates both SVGs
python3 tools/calc.py               # regenerates parameters_auto.scad + docs
```

**Verified by computation**

- every centre distance equals `m(z₁+z₂)/2` to the last digit, on every mesh
- ratios close exactly: 24.000, 60.000, 4.000, 12.000
- the carriage is at 1.000 rpm **because** the balance is at 1.000 Hz
- every mesh is conjugate: one tooth system and one shared describing circle per
  mesh, **zero tooth collisions** over a swept 41-phase mesh, and a contact ratio
  measured from the generated profiles (minimum **1.2130**, on the fixed-fourth ↔
  escape-pinion mesh, which is the binding one)
- no interference between any two members, in XY **and** in Z
- nothing enters the volume the carriage sweeps as it turns
- every bridge window is at least 1.0 mm larger than the members declared to pass
  through it; every plate window leaves at least the process minimum wall to the
  rim (C-18d)
- mainspring: σ = 1400 MPa at full wind, 10.589 J stored, 3.231 turns, 3.23 days
- hairspring σ = 750 MPa against a 1400 MPa limit
- available escape torque 1.2126 N·mm against 0.7384 N·mm required (× 1.64 margin)
- carriage static moment, poise specification and counter-mass
- clock Ø300.00 and carriage tip Ø68.60 against the 70 mm target

**Not verified, and why**

- **The `.scad` files have never been compiled** — no OpenSCAD binary exists in
  this environment and none could be installed. What was done instead is a
  static linter (L-01 … L-11). A linter is not a compiler: install OpenSCAD and
  render `main.scad` before trusting the model visually. See **L-17**.
- **The STL set is partial.** `tools/gen_stl.py` verifies each part by three
  measurements before writing it (signed volume against analytic volume, closed
  and consistently oriented edges, finite bounding box). Last run: **25 parts
  written, 21 refused** because their cross-sections need two void loops sharing
  a boundary, which the pure-Python hole-bridging triangulator cannot make into
  one watertight cap. Refusals are printed with the reason and with the exact
  OpenSCAD command that will produce them. See **L-16**.
- **Tolerances are uncalibrated starting points**, to be replaced by values
  measured from calibration coupons on your own equipment. See **L-14**.
- **Timekeeping is not demonstrated at all.** See **L-01 … section 1** of the
  limitations register.

## Two real defects the verification found

Both would have been silent in a compiler, and both were fixed at the source.

1. **A name collision that would have destroyed every tooth count.**
   `parameters.scad` includes `parameters_auto.scad` and then declared thirteen
   Z-stack ranges with the *same names* as tooth counts — `Z_GREAT_WHEEL = 56`
   against `Z_GREAT_WHEEL = [2.0, 4.0]`. In OpenSCAD the last assignment wins, so
   every gear in the train would have been built from a list instead of an
   integer. The ranges are now `ZR_*`, and lint check **L-11** fails the build if
   any constant is ever declared twice.

2. **A plate window exactly tangent to the plate rim.** The barrel drum passage
   was `BARREL_DRUM_OD + 4.0 = Ø156.0` at (0, 70), which reaches
   70 + 78 = **148.000 mm** — precisely the plate radius, leaving *zero*
   material at 12 o'clock. Only the STL path exposed it, because the tangency
   makes any 2-D boolean degenerate. The window is now Ø154.0 (1.000 mm rim
   margin) and check **C-18d** tests every window's rim margin against the
   selected process's minimum wall.

A third was caught earlier and is the reason the motion works has two modules:
a single module cannot place the hour wheel concentric with the centre arbor
while the minute wheel and minute pinion share one stud — it would misplace the
hour wheel by **7.200 mm**. Check **C-07b** now proves both meshes span exactly
28.8000 mm.

## Regenerating

`parameters_auto.scad`, `design.json`, `BOM.csv` and every file in `docs/`
except `ASSEMBLY.md`, `LIMITATIONS.md` and the two SVGs are **generated**. To
change a dimension, edit `tools/design.py`, then:

```sh
python3 tools/calc.py          # revalidate and regenerate everything
python3 tools/profile_check.py # re-measure the tooth profiles
python3 tools/scad_lint.py     # re-lint the SCAD (catches a stale parameters_auto)
python3 tools/gen_drawings.py  # redraw both sheets
python3 tools/gen_stl.py       # rewrite and re-verify the STLs
```

`tools/gen_stl.py` calls `cross_check()`, which compares every constant it read
out of the `.scad` files against `tools/design.py` and fails if they disagree —
that is what detects a stale `parameters_auto.scad`.

Never hand-edit `parameters_auto.scad`.
