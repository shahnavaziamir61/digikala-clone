### Profile choice

Wheels with `z >= 17.1` are **involute**, full depth, zero profile shift.  Pinions with `z < 17.1` would undercut as involute gears, so they are declared **cycloidal pinions** (epicycloid face / hypocycloid flank), which is the classical horological solution and has no undercut at any `z >= 6`.  This is NOT a cosmetic choice: mixing an involute wheel with a cycloidal pinion requires the wheel flank to be generated against the pinion, which `gear_generator.scad` does when `PROFILE="cycloidal"`.
